NEMES Miner v0.2.0 (Linux, testnet) — Hizli kurulum (18 Eyl 2026 guncel)

GEREKSINIM: NVIDIA GPU + CUDA surucu (gomme icin). Islemci modunda da
calisir ama yavastir. Ayrica bir embed-api gerekir (adim 2).

1) Kayit:
   curl -s -X POST https://komuta.nemes-x.space/api/kayit \
     -H 'Content-Type: application/json' \
     -d '{"cuzdan":"TRC20_ADRESIN","makine_id":"ev-pc-1"}'
   -> donen "token" alanini kaydet (bir daha gosterilmez).

2) Gomme ucu (IKISINDEN BIRI SART - madenci metni sayiya ceviremezse
   uretemez). Miner adresin sonuna /v1/embeddings ekler; o yuzden TABAN
   adresi ver (ornekler asagida).
   A) LM Studio (bugun calisir): nomic-embed-text-v1.5 modelini indir,
      Server sekmesinde baslat (varsayilan port 1234). Ardindan:
        --embed-api http://127.0.0.1:1234
      (Farkli port sectiysen onu yaz.)
   B) NEMES gomuntu paketi (onerilen, tek-dosya): nemes-bundle (1.3GB,
      llama-server + model icinde) indirme baglantisi cok yakinda bu
      sayfada duyurulacak. Kurulum:
        ./start-embed-server.sh 1251
      Ardindan --embed-api http://127.0.0.1:1251 kullan.

3) Calistir (ornek - token ve embed-api kendine gore; asagida LM Studio
   varsayilmis, gomuntu paketiyle 1251 yaz):
   ./nemes-miner mine --simple \
     --komuta https://komuta.nemes-x.space \
     --token TOKEN \
     --embed-api http://127.0.0.1:1234 \
     --kira --kira-adet 2000
   (--kira: gorevleri toplu kiralar, baglantiyi rahatlatir. Ilk surumde sart degil.)

4) Durum: ./nemes-miner status --watch
   Bosluk onerisi (opsiyonel, stake'li; token gerekir):
     ./nemes-miner bosluklar --komuta https://komuta.nemes-x.space --token TOKEN
