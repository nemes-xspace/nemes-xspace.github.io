5b. Miner Binary Verification

Downloaded miner must match the signed checksum before running:

sha256sum -c SHA256SUMS
ssh-keygen -Y verify -f allowed_signers -I nemes-release -n nemes-release -s SHA256SUMS.sig < SHA256SUMS

Release key (nemes-release) is published in the miner README. "Good signature" required — otherwise do not run, report by email.
